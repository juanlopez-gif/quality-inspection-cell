How to read this graph

Rectangles are ROS 2 nodes, pills are topics. The supervisor is the only node that sends commands. Devices only execute commands and report status. The IR sensor has no command topic: it is purely reactive.

Click any node or topic for details.

Decision cycle of the supervisor
A device publishes a STATUS
→
Supervisor updates its view of the cell
→
Evaluates the rules in order (safety first)
→
Publishes COMMANDS (only if something must change)

Rules are also evaluated by a 10 Hz timer so time-based rules (sensor timeout, inspection timeout) work even when nothing is published. Source: quality_cell/core/supervisor_rules.py
